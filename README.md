Gred's TLDR
A Discord bot that generates TL;DR summaries of conversations/messages, with support for creating news-broadcast-style graphics.

✨ Features
Summarizes long text/messages into short TL;DRs.

Discord bot integration (slash/prefix commands — προσάρμοσε ανάλογα).

Generates "news broadcast" style images for summaries.

Custom fonts bundled in fonts/ for consistent rendering.

🧱 Tech Stack
Python (see requirements.txt for dependencies)

Discord bot framework (π.χ. discord.py — επιβεβαίωσε από το requirements.txt)

Image generation library (π.χ. Pillow) για τα news graphics

📋 Requirements
Python 3.9+ (προσάρμοσε ανάλογα)

A Discord bot token
